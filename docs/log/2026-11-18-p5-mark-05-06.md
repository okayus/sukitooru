## 章の直し（第6章 buildDEC の JNZ）

差し込みで許された 1 か所。場面1 段階5（プログラムの 8 命令を 4.2 秒ずつ巡る）と場面3 段階3（ADD 11）の板の関数 buildDEC が、JNZ のときもオペランドの札を「オペランド 0000 = 0 番地 → そのままアドレスバスへ（解読しない）」と出し、アドレスバスへの線（`bus`）を d の色で光らせていた。同じ板の合図の表では JNZ は「PC ← 番地」だけに ● がある。

直した所（`frame` の中の 2 行を 3 行に）: JNZ（op 5）のときは `bus` を光らせず、解読が終わった後（ph 4）の札を「オペランド 0000 = 0 番地 → PC の入口へ（飛び先。解読しない）」にした。ADD・SUB・LOAD・STORE は今までどおり、HALT は「HALT はオペランドを使わない」のまま。言い方は部品 dec の段階1 の札（「→ PC の入口へ（飛び先。解読しない）」）に合わせた。

```js
const toBus = op && op !== 5;
bus.setAttribute('class', 'f-none round ' + (ph >= 4 && toBus ? 's-d w3' : 's-dim w3'));
opTxt.textContent = ph >= 4 ? (toBus ? `… → そのままアドレスバスへ（解読しない）` : op ? `オペランド ${bits4(n)} = ${n} 番地 → PC の入口へ（飛び先。解読しない）` : 'HALT はオペランドを使わない') : 'オペランド（下位 4 ビット）→ アドレスバスへ';
```
