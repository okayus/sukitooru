### 判断

- 第1章は 2 つ下の層だが、コンデンサ・抵抗と長さ・スイッチの回路・オームの法則・発熱・導体と絶縁体の道の説明は第2章に無く、第1章が一番近い。行き先を第1章にした。
- s5.4 のゲートのトンネル電流 → 第5章 場面6 段階2 は、向きが「横」。トンネル効果を説明している場面は教材にこれ 1 つで、層の登録簿の down（transistor → handoutai → denshi）からは届かない。上は厚さ 1〜3 nm・1 V 前後の直接トンネル、下は 7〜10 nm・約 20 V の FN トンネリングなので「例が違う」。
- s2.2 の空乏層は「例が違う」。下（第2章 場面4 段階3）は拡散と再結合でできる pn 接合の空乏層、上はゲートの＋電荷が正孔を押し下げてできる空乏層。残るのが格子に固定された−イオン、という点は同じ。
- pMOS は「無い」にした。第3章 場面3 段階6 は「ゲートを低くするとチャネルができる」と結果を述べるだけで、nMOS（場面2）のように表面の変化を見せる場面が無い。第4章 場面2 の P1・P2、第5章 場面4 の引き上げ側も同じ所に頼る。
- s3.3・s4.1・s4.5・s5.3・s5.6・s6.5 は同じ章の場面（同じ層）へ。スイッチ・インバータ・発熱・製造の場面が、チャネル（場面2）とゲートの容量（場面1）に頼り、そのすぐ下の説明がこの章の中にあるため。s5.6（f を上げるには V も要る）は、本文に理由が無いが、場面2 段階4（V_G − V_th が大きいほど流せる電流が増える）と場面3 段階4（切り替えの時間は容量の充放電）から言えるので「有る」にした。
- s4 の C には印を 3 本付けた（段階1・段階2・段階3 と 5）。同じ要素でも、段階ごとに頼る仕組み（ゲートが容量になる理由・充電・放電）が違うため。札の位置は同じで、同時には出ない。s3 の nMOS の記号（段階2 と 3）、s4 の nMOS（段階4 と 5）も同じ作り。
- s3.1 の「第1章の回路でレバーがあった場所」は回路の置き換えの説明で、仕組みには頼らない。段階2 の「輪が切れる」が頼る第1章 場面5 段階2 に印を張った。
