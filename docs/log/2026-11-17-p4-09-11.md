### 判断

- 場面2 段階2 の印は、レンダラの箱のスレッドの三角ではなく、CPU のコアの枠に付けた。最後の三角と箱の枠の間は 28px で、26px の札を置くと両方に接する。コアの枠は「いま走っているスレッド」を示し、走っているスレッドのレジスタがコアに入っていることと合う。
- 場面2 段階4・場面5 段階5・場面6 段階2 の 3 本が同じ 07-shuuhen.html#s4.4 を指す。どれも NIC の割り込み（受信を書き終えてから 1 回）に頼るので行き先を揃え、つなぎの一文を場面の語に合わせた。
- 場面4: mmu-walk は「無い」。印は「有る」依存（DRAM、キャッシュ、TLB、ページの印の照らし合わせ、#PF の入口、SSD）に張った。ページの印 → 部品 cpu-mode 段階4 は、部品が U/S の例なので「例が違う」（P・R/W・NX も同じ形の照らし合わせ）。段階5 では表の列が薄くなり、札が共有メモリの矢印の先に寄るので、段階4（PT の行）と段階5（属性の文の行）を別の印にした。
- 場面4 段階4 の #PF → 07#s3.4 は「例が違う」。割り込みは命令を終えてから次の番地を保存するが、#PF は止めた命令の番地を保存してやり直す。この違いをつなぎの一文に書いた。
- 場面5: ctx-switch は「無い」。印はタイマ割り込み（07#s3.4。キーボードの例なので「例が違う」）とレジスタ（06#s1.2）に張った。レジスタの札は、交代の矢印（レジスタ → 次の task_struct）が出るときも重ならない位置（矢印の横線の 7px 下）に置いた。
- 場面5 段階4 の赤黒木 → 27#s4.1 は「横」（os の down に algo が無い）。27#s4.1 は本文で第9章 場面5 の赤黒木を名指しし、釣り合いと O(log n) を説明するので張った。C ステート → 03#s5.4 は os → cpu → ronri → transistor で「下」。
- 場面6: nic-rx は「無い」。印は個々の仕組み（MMIO・ディスクリプタ・DMA・割り込み・EtherType・プロトコル番号・経路表・NIC の送信）に張った。場面6 の層は os と transport を兼ねるので、UDP（第19章）は「同じ層」として見送り、Ethernet（第13章）・IP（第18章）・経路表（第14章）は「下」になる。段階2 は印が 3 つ（上限）。
- 場面1・3 の見送りの行は、P2 の印の後に見つけた依存。足すかは調整役が決める。
- P2 の印で変えたのは、場面1 段階3「システムコールの入口」に `at: [266, 250]` を足したことだけ。調整役が厳しくした札の検査（幅 4px 以上で文字の高さの 3 割以上を覆えば拾う）で、既定の位置（文字の右上）の札が「システムコール入口」の末尾を隠すと出たため。札は同じ文字の右隣で、行き先・段階・つなぎの一文は変えていない。

### 判断

- 第11章は層の全体を見せる章で、登録簿は場面ごとに見せる層を全部持たせている（11-2・11-3 は phy〜http、11-5 は ip だけ、11-1・11-6 は phy・link・ip）。そのため、ip の章（第14・16・18章）への印は 11-1・11-5・11-6 で「同じ層」、transport・http の章（第17・19章）への印は 11-5・11-6 で「横」になる。どれも概観が頼る仕組みの詳しい説明で、指示（行き先は第12〜19章のその層の仕組み）どおり張った。同じ層 6 本・横 4 本。
- 場面3 段階1 の HTTP の要求文 → 21#s1.1 は「同じ層」で第12〜19章の外なので見送った。段階2〜6 に印がある。
- 場面2 段階4 の章の対応表は、札がそのまま章へのリンクなので印を張らない。場面6 は段階1・4・6 に印が無い（段階1 は場面1 と同じ機器、段階4 はサーバーの側で第22〜24章＝横、段階6 は読み方の案内）。
- 場面5 段階4 は、待ち行列 → 18#s4.5 と受け皿 → 19#s3.4 の 2 本。受け皿には段階3（並べ直し → 19#s3.3）と段階4（再送）の 2 本を同じ位置に付けた。段階ごとに 1 本ずつ出る。
- 場面3 段階5 のビット列 → 13#s2.3 は「例が違う」。上の段階は 358 バイトのフレーム、第13章は別のビットの例。P5 の line-code の候補。
- 札の位置: 場面1 段階3 のルーターの 3 行は、行の右端の外に札を縦に並べた。場面4 の上段の札（MAC・IP・ポート）の印は、札の右上の角に置いた。場面6 段階2 の OLT の札は箱の右上の角（右隣の「光」の文字と ISP の層の積み重ねから離した）。
