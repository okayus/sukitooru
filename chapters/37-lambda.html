ラムダ計算

関数型は、計算機の何に立ち向かうのか。第6章の CPU はレジスタとメモリを命令ごとに書き換える状態機械で、命令型の言語はそれを変数と代入で写している。関数型の言語が土台にするのは、式を等しい式で置き換えていく計算のモデル、ラムダ計算である。この章では、変数・抽象・適用の 3 つの形と β簡約の規則だけで、数・真偽・再帰まで書けることを、小さな項を 1 歩ずつ簡約して確かめる。

1状態か、式か — 計算の 2 つのモデル

YT-8 の 22 命令sumTo 3参照透過性

第36章の評価器は、構文木を歩きながら環境に名前と値を足し、書き換えた。その下の CPU も、命令ごとにレジスタとメモリを書き換える。同じ 3 ＋ 2 ＋ 1 を、式の置き換えだけで計算すると何が違うかを比べる。

Backus は 1977 年のチューリング賞講演で、CPU とメモリの間で語を 1 つずつ運ぶ通り道を「フォン・ノイマン・ボトルネック」と名付けた。参照透過性の語は、Strachey が 1967 年の講義ノートで、哲学者 Quine から借りた。

23 つの形 — 変数・抽象・適用

xλx. MM Nα変換

λ計算の項は、変数・抽象・適用の 3 つの形でできている。数も if も代入も無い。この章で使う記法と、名前がどの λ に結び付くか（束縛）の規則を決める。

λ記法は、Church が 1932・1933 年の 2 本の論文で、論理の土台として出した。その論理には Kleene と Rosser が 1935 年に矛盾を示し、関数を扱う部分だけが λ計算として残った。

3β簡約 — ただ 1 つの計算の規則

(λx. M) N → M[x := N]簡約基変数の捕獲

計算の規則は 1 つだけ。関数に引数を渡した形を見つけたら、本体の中の仮引数を引数で置き換える。置き換えられる形が無くなるまで、これを繰り返す。

数と組み込みの演算の規則（δ簡約）は、純粋な λ計算には無い。場面5 で、数と足し算も λ だけで書く。置き換えでは同じ引数が何か所にも写るので、引数を先に簡約するかどうかで手間が変わる（場面4）。

4順序と合流性 — どこから簡約しても答えは 1 つ

適用順序正規順序Church–Rosser 1936Ω

1 つの項に簡約基が 2 つ以上あると、どれから簡約するかを選べる。選び方で途中の歩みは変わるが、行き着く答えは変わらない。ただし、選び方によっては止まらなくなる。

多くの言語の値呼びは、引数を先に計算する点で適用順序に近いが、関数の本体（λ の中）は呼ばれるまで簡約しない点が違う。Haskell の遅延評価は正規順序に近く、同じ引数を 2 回計算しない工夫を足している（第40章 場面1）。

5数もデータも関数 — Church の符号化

true・false3 = λf. λx. f (f (f x))pluspair

λ計算には数も真偽も無い。それでも 3 つの形だけで、真偽・数・対を関数として書ける（Church の符号化）。値そのものではなく、その値を使って何をするかを関数にする。

Church は 1933 年の論文の終わりでこの数の表し方を示した。実際の言語は、真偽・数・対を直和・直積の型とビットの並びで持つ（第29章 場面2）。同じ定義を Haskell で書き、plus 2 1 に 1 を足す関数と 0 を渡すと 3 が返った（GHC 9.6.7）。

6再帰と、計算できること — 不動点と答え

YChurch 1936Turing 1937Haskell

λ には名前が無いので、関数が自分を呼ぶには工夫が要る。不動点コンビネータを使えば再帰も 3 つの形で書け、λ計算はチューリング機械と同じだけのことを計算できる。

不動点コンビネータは Y だけではない。Turing が 1937 年に示した Θ は、Θ G が G (Θ G) にそのまま簡約される。値呼びの JavaScript では、Y の x(x) を v => x(x)(v) と包むと止まり、6 を返した。

7まとめ — ラムダ計算

  1. 第6章の CPU は状態を命令ごとに書き換え、命令型の言語はそれを変数・代入・文の並びで写す。式の置き換えで計算すると書き換わる場所が無く、式を等しい式で置き換えられる（1）。
  2. λ計算の項は、変数・抽象・適用の 3 つの形だけ。変数は根の方へたどって最初に出会う同じ名前の λ に束縛され、束縛変数の名前は付け替えてよい（2）。
  3. 計算の規則は β簡約 (λx. M) N → M[x := N] だけ。自由変数が捕まるときは先に α変換する。処理系の多くは書き写さず、環境に記録する（3）。
  4. どの簡約基から簡約しても、止まる限り答えは 1 つ（合流性）。Ω のように止まらない項もあり、正規順序は正規形があれば必ずそこに着く（4）。
  5. 真偽・数・対も関数で書ける（Church の符号化）。数 n は f を n 回当てる関数で、plus 2 1 は β簡約 6 回で 3 の形になる（5）。
  6. 再帰は不動点コンビネータで書け、λ計算はチューリング機械と同じ関数を計算できる。関数型が立つのは、状態の書き換えではなく式の置き換えという計算のモデル（6）。
ラムダ計算（λ計算）変数 x・抽象 λx. M・適用 M N の 3 つの形と β簡約だけで計算を表す体系。Church が 1932〜36 年に作った。
束縛変数・自由変数λx. M の中でその λ に結び付く x と、どの λ にも結び付かない変数。λx. x y の x は束縛変数、y は自由変数。
α変換束縛変数の名前を、束縛する λ と使う所をそろえて付け替えること。λx. x と λy. y は同じ項。
β簡約・簡約基(λx. M) N を、M の自由な x をすべて N にした M[x := N] に書き換える規則と、その形（λ への適用）。
正規形簡約基を含まない項。計算の答えにあたる。Ω ＝ (λx. x x) (λx. x x) のように正規形を持たない項もある。
正規順序・適用順序最も左で最も外側の簡約基から簡約する順と、中に簡約基を含まない最も左の簡約基から簡約する順。値呼び（第40章）とは別。
合流性（Church–Rosser の定理）1 つの項を 2 通りに簡約しても、さらに簡約すれば同じ項に着けるという性質（1936 年）。正規形は、あれば 1 つ。
Church の符号化真偽・数・対を関数で表す方法。true ＝ λt. λf. t、3 ＝ λf. λx. f (f (f x))（f を 3 回当てる）。
不動点コンビネータ（Y）Y G と G (Y G) が等しくなる項。Y ＝ λf. (λx. f (x x)) (λx. f (x x))。名前の無い λ で再帰を書くのに使う。
参照透過性式を等しい式（その値）で置き換えても、全体の意味が変わらない性質。Strachey が 1967 年に Quine から借りた語。

第X部の残りの章は、実際の関数型言語がこの 3 つの形に足したものを 1 つずつ見る。次の第38章では、関数を数と同じ値として渡し、返し、しまうと、機械の上で何になるかを追う。
