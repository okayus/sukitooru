37 個のトークンを、規則ごとの関数が呼び合って木に組む（再帰下降）。節は 13 種の enum Node で、Program の body に文が 3 つ並ぶ。ここでは 2 つめの文の木を追う。

ECMAScript の式の文法は、AssignmentExpression から最初の選択肢をたどると PrimaryExpression まで 20 段（2026 年 11 月閲覧）。saba はそのうち同じ名前の 5 段で、条件・論理・比較・* / の段は無い。

3評価と環境 — eval・RuntimeValue・Environment

できた木を JsRuntime が根から歩いて評価する。値は型の札を付けた RuntimeValue、変数は名前と値の対を並べた Environment に入る。木の節を 1 つずつ match で読む評価器である。

ECMAScript の数は IEEE 754 の 64 ビット（第26章 場面4）、saba の Number は u64。片方が文字列なら + が連結になるのは同じ。- は仕様なら文字列を数に直し（"5" - 1 は 4）、直せなければ NaN。saba は 0 にする。

7まとめ — JavaScript エンジン

  1. JsLexer は script の文字列を先頭から読み、空白を飛ばし、予約語（var・function・return）を先頭一致で見て、記号 10 種・数・識別子・文字列の 5 種のトークンに切る。test.html では 37 個（1）。
  2. JsParser は規則ごとの関数が呼び合う再帰下降で、13 種の enum Node を Rc でつないだ木を作る。assignment → additive → left_hand_side → member → primary の呼び出しの深さが優先順位になる（2）。
  3. JsRuntime は木を歩く評価器。値は Number・StringLiteral・HtmlElement の 3 つの札を持つ RuntimeValue、変数は Vec の対を線形探索する Environment。未定義の名前はその名前の文字列になる（3）。
  4. 関数は functions の Vec に積み、呼ぶときは outer を呼び出し側にした新しい環境を作って引数を結び、BlockStatement の最後の文の値を返す。add(1, 2) は Number(3)（4）。
  5. document.getElementById は "document.getElementById" という文字列との一致で呼ばれ、DOM のノードへの Rc<RefCell<Node>> を HtmlElement として返す。textContent への代入が set_first_child で Text を差し替える（5）。
  6. JS は DOM が全部できてから 1 回だけ走り、その後にレイアウトと描画が続く。Chromium はパーサを止め、イベントループで何度も走らせる。V8 のバイトコードと JIT に対し、saba は木を歩くだけ（6）。
JsLexer と Token文字の列を Punctuator(char)・Number(u64)・Identifier・Keyword・StringLiteral の 5 種のトークンに切る反復子（impl Iterator）。test.html の script は 37 個。
予約語（RESERVED_WORDS）var・function・return の 3 語。先頭一致で見る。ECMAScript の ReservedWord は 38 語（2026 年 11 月閲覧）。
構文木（Node・Program）13 種の enum Node を Rc<Node> でつないだ木。Program.body は文の列（例では 3 つ）。作った後で書き換えないので RefCell は無い。
再帰下降文法の規則ごとに関数を 1 つ書き、互いに呼び合って木を組む解析法。parse_ast → source_element → statement → 式の関数の順に呼ぶ。
優先順位（呼び出しの深さ）assignment → additive → left_hand_side → member → primary の順に呼び、深い関数ほど強く結び付く。右辺が assignment_expression なので右結合、と読める。
RuntimeValue評価の結果。Number(u64)・StringLiteral(String)・HtmlElement { object, property } の 3 種の札を持つ enum。値が型を持ち歩く動的な型。
Environmentvariables: Vec<(String, Option<RuntimeValue>)> と outer。get_variable は線形探索し、無ければ outer へ。関数の呼び出しごとに新しく作る。
関数呼び出しfunctions の Vec から名前（文字列）で探し、引数を新しい環境に add_variable し、BlockStatement の最後の文の値（ReturnStatement の argument）を返す。
ブラウザ API（call_browser_api）callee が "document.getElementById" という文字列に等しければ get_element_by_id を呼ぶ。この版の唯一の API。
HtmlElement と textContentDOM のノードへの Rc<RefCell<Node>> と property を持つ値。property が "textContent" のとき、代入が set_first_child で Text ノードを差し替える。
