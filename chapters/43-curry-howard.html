1同じ形の規則 — 型は命題、プログラムは証明

→除去適用→導入λ抽象

第42章は、作用を戻り値の型に出し、型を見れば何が起こりうるかが分かるようにした。この章は、型そのものが論理の命題として読めることを見る。まず、論理の推論規則と型検査の規則を並べる。

記号の読み: → ならば、∧ かつ、∨ または、¬ でない、⊥ 偽、∀ すべての、∃ ある。場面1〜4 の論理は自然演繹の命題論理で、場面5 で ∀・∃ を足す。Haskell の型変数 a・b は、図の命題 A・B に当たる。

2「かつ」「または」「ならば」はデータ型

(a, b)Either a ba -> b

場面1 の対応は「ならば」だけだった。論理には「かつ」「または」もあり、それぞれに当たる型は第29章で数えた直積と直和である。命題を証明することは、その型の値を作るプログラムを書くことになる。

ghci が表示する型変数の名前（p・t1 など）は ghci が付けたもの。名前を付け替えても同じ型で（α変換。第37章 場面2）、同じ命題を表す。表の (x, y) の x・y は、それぞれ A・B の証明。

3偽と否定 — 直観主義論理

Voidabsurda -> Void

場面2 の表には「でない」が無かった。否定を型にするには、まず「偽」に当たる型が要る。ここで、型として読める論理が、普通の数学で使う古典論理と違う所が出てくる。

古典論理にも計算としての読みがある。Griffin は 1990 年に、制御の演算子 call/cc に Peirce の法則 ((A → B) → A) → A の型が付くことを示した。図3 の段階5 の callCC も、ContT を消すと同じ形をしている。

4評価は証明の整理 — 回り道を消す

fst (a, b)β簡約正規形

場面1〜3 は、型を命題、項を証明として読んだ。では、項を評価することは、証明の側では何に当たるか。第37章の β簡約を、証明の木の上でたどる。

自然演繹の正規化定理は Prawitz が 1965 年の本で示した。Gentzen は 1935 年の論文で自然演繹を導入し、同じ論文で、別の体系（シーケント計算）の回り道を消す定理（カット除去）を示した。

5「すべて」「ある」と依存型

forallΠ・ΣVec n a証明支援系

場面1〜4 の論理には「すべての」「ある」が無かった。値についての命題、たとえば「どの自然数 n でも n + 0 = n」を型にするには、型が値に依存できなければならない。

図5 の Lean のコードは Lean 4 の文法で書いたが、手元では動かしていない。GHC の Vec の長さは型の段の Nat で、値の段の数とは別物なので、依存型を真似たもので、依存型そのものではない（実行時の値から型の長さを作るには、さらに工夫が要る）。

6どこまで信じられるか — 第X部の答え

undefined全域性第37〜43章

型検査が証明の検査なら、型の付いたプログラムはどこまで信じられるか。Haskell の論理としての穴と、それを塞ぐ証明支援系の代償を見て、最後に第X部の問いに答える。

第X部の答えは、関数型を命令型より上に置くものではない。Rust は所有と借用で書き換えを残し、別名と書き換えを同時には許さない（第39章 場面1）。コンパイラの中間表現 SSA も、値を 1 回だけ決める形を使う。

7まとめ — 型は命題、型検査は証明検査

  1. 論理の推論規則と型の規則は同じ形で、型の規則から項を消すと論理の規則になる。命題は型、証明は項、仮定は変数、含意の除去は適用、導入は λ抽象に当たる（1）。
  2. A ∧ B は組 (a, b)、A ∨ B は Either a b、A → B は関数。命題を証明することは、その型の止まる項を書くことで、GHC の型検査がその証明を検査する（2）。
  3. 偽は値の無い型 Void、否定 ¬A は a -> Void。排中律と二重否定の除去には項が無く、型として読める論理は直観主義論理になる（3）。
  4. 導入してすぐ除去する回り道を消す操作が、β簡約と場合分けの簡約に当たる。評価は証明の正規化で、単純型付きの閉じた Either の項は Left か Right まで評価できる（4）。
  5. 値についての「すべて」「ある」は依存型の Π 型と Σ 型。長さを型に持つ列は範囲外を実行の前に防ぎ、依存型の証明支援系は、その型で書いた証明を検査する（5）。
  6. 止まらない項を許す Haskell は論理として穴があり、証明支援系は全域性を検査する。関数型は書き換えできる状態と順序に立ち向かい、機械との差は処理系が埋める（6）。
カリー＝ハワード対応命題と型、証明とプログラム、証明の正規化と評価の対応。Curry（1934 年）と Howard（1969 年の原稿、1980 年に出版）。
自然演繹結合子ごとの導入と除去の規則で、証明を木に組む論理の体系。Gentzen（1935 年）。
含意（→）「ならば」。導入は λ抽象、除去は関数の適用に当たる。型では関数の型 a -> b。
連言と直積A ∧ B（かつ）は組の型 (a, b)。導入は組を作ること、除去は fst・snd。
選言と直和A ∨ B（または）は Either a b。証明はどちらの側かの印を持ち、除去は場合分け（either）。
空の型（Void）値が 1 つも無い型で、偽 ⊥ に当たる。否定 ¬A は a -> Void。absurd :: Void -> a。
直観主義論理証明を作り方として読む論理。排中律 A ∨ ¬A と二重否定の除去 ¬¬A → A を一般には認めない。
証明の正規化導入してすぐ除去する回り道を消すこと。項では β簡約と場合分けの簡約。どの証明も正規形に直せる（Prawitz、1965 年）。
依存型値に依存する型。Π 型（関数）が「すべて」、Σ 型（値と証明の組）が「ある」に当たる。
証明支援系と全域性証明を機械が検査する言語。依存型を土台にするもの（Rocq・Agda・Lean など）と、高階論理の Isabelle/HOL などがある。全域性は、どの入力でも止まり、場合分けに漏れが無いこと。
