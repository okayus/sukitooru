高階関数とクロージャ

第37章のλ計算では、関数を引数に渡すのも、関数を返すのも、ふつうの式だった。この章では、関数を数と同じ値として扱う言語で、関数を受け取る関数（高階関数）が手順の骨組みを部品にする書き方と、それが機械の上で何になるかを見る。関数の値は機械語の番地と環境の組（クロージャ）になり、再帰の繰り返しは、最後にすることが呼び出しだけならループになる。

    関数を渡す・返す・しまう。map は関数を受け取る関数。C の関数ポインタとの違い。

  2. 2クロージャ

    関数の値は、コードの番地と自由変数の環境の組。Rust と V8 の実物、字句的スコープ。

  3. 3カリー化

    引数を 1 つずつ受け取る形にすると、一部だけ渡せる。処理系は毎回は作らない。

  4. 4合成

    部品の出力を次の入力につなぐ。型が合えばつながり、機械の上では 1 つのループになる。

  5. 5畳み込み

    リストの 2 つの形に沿った再帰と、それを 1 つにまとめた foldr。

1関数は値 — 渡す・返す・しまう

map(*2)第一級関数ポインタ

第37章のλ計算では、関数を引数に渡すのも返すのも、ふつうの式だった。実際の言語は数やリストを機械の表現で持ち、関数をそれらと同じ値として扱えるかは言語によって違う。

「第一級」は Strachey の 1967 年の講義（2000 年に出版）の言葉。ALGOL の実数は式に書け、変数に代入できるが、手続きは呼ぶか引数に渡すことしかできないので「二級の市民」だ、と書いた。

2クロージャ — コードと環境の組

addN 3自由変数E0373size_of_val%DebugPrint

関数を返す関数では、返した関数の本体が、もう終わった呼び出しの引数を使う。式の上では引数を置き換えれば済むが、機械の上の関数の値は、コードの番地だけでは足りない。

JavaScript のクロージャは、値の写しでなく変数そのものを持つ。addN の中で f を作った後に n = 10 と代入すると、addN(3)(2) は 12 になった。Rust の move は値を写し、Haskell の変数は書き換えない。

3カリー化と部分適用 — 引数を 1 つずつ渡す

Int -> Int -> Intadd 3currySTG

場面2 の addN は、Int を 1 つ受け取って関数を返した。2 つの数を足す関数も、同じ形で書ける。引数を 1 つ受け取るたびに関数を返す形にすると、引数の一部だけを先に渡して部品を作れる。

多引数の関数を 1 引数の関数の連なりで表す考えは、Schönfinkel の 1924 年の論文（Mathematische Annalen 92 巻）にあり、Curry が組合せ論理で多く使った。カリー化の名は Curry から来ている。

4関数合成 — 部品をつなぐ

(.)filter oddmap (*2)sum

部分適用で作った部品は、出力を次の部品の入力につなげられる。つないだものも 1 つの関数で、途中の値に名前を付けず、書き換える変数も置かずに手順を書ける。

JavaScript の配列の filter と map は、仕様どおり途中の配列 [3,1] と [6,2] を作ってから次へ渡す。要素を 1 つずつ流して途中を作らない書き方は、遅延評価と Iterator の話になる（第40章 場面6）。

5再帰と畳み込み — データの形に沿って

[]x : xsfoldr

Haskell にはループの文が無く、繰り返しは再帰で書く。リストは「空」か「先頭と残り」の 2 つの形しか無いので、リストの関数は 2 つの場合の式で書ける。その形を 1 つにまとめた高階関数が foldr である。

左から畳む foldl は ((0 + 3) + 2) + 1 の形を作る。足し算では答えは同じ 6 だが、引き算では foldr (-) 0 [3,2,1] が 2、foldl (-) 0 [3,2,1] が -6 と違う。foldl の代償は第40章 場面5。

6末尾呼び出し — 繰り返しの状態を引数に

sumTogo acc njmp-O2

再帰で繰り返すと、呼び出しのたびにスタックの枠が 1 枚積もる。関数が最後にすることが呼び出しだけなら、いまの枠を使い回せる。機械語では、これは呼び出しではなく先頭へ戻る飛び越しになる。

GHC は足りなくなるとスタックを伸ばすので、手元の GHC 9.6.7 では末尾でない sumTo 1000000 も 500000500000 を返した。RTS の -K で上限を小さくすると、Stack space overflow で止まる。

7まとめ — 関数を値にする

  1. 関数を数と同じように渡し、返し、しまえるとき第一級の関数と呼び、map のように関数を受け取る関数を高階関数と呼ぶ。C の関数ポインタは番地だけで、実行中に関数を作れない（1）。
  2. 関数の値は、コードの番地と自由変数の値を入れた環境の組（クロージャ）。Rust は捕まえた変数を欄に持つ構造体、V8 は Context を指す関数の物で表す（2）。
  3. Int -> Int -> Int は Int -> (Int -> Int) で、引数を一部だけ渡す部分適用で部品を作れる。カリー化は関数の形を変えることで、別の語（3）。
  4. 合成 f . g は、型の合う部品を、途中の名前も書き換える変数も無しにつなぐ。rustc -O と GHC -O2 は、つないだ全体を 1 つのループにした（4）。
  5. リストの 2 つの形に沿った再帰を 1 つにまとめたのが foldr で、: を f に、[] を z に置き換える。有限のリストなら、f が止まる限り止まる（5）。
  6. 最後が呼び出しだけなら枠を使い回せ、機械語では先頭へ戻るループになる。繰り返しの状態は累積引数に移り、保証は言語ごとに違う（6）。
第一級関数引数に渡す、戻り値にする、名前やデータ構造にしまうの 3 つが、数と同じようにできる関数。Strachey の 1967 年の講義の言葉。
高階関数関数を受け取るか返す関数。map・filter・foldr・(.)。
クロージャ・環境関数の値を、コードの番地と、自由変数の値を入れた環境の組で表したもの（Landin、1964 年）。Rust で i32 を 1 つ move すると 4 バイト。
字句的スコープ関数の中の名前を、定義した場所の環境で探す決まり。呼び出した側で探す決まり（第36章の saba）は動的スコープ。
カリー化組を受け取る関数を、引数を 1 つずつ受け取る関数の連なりに変えること。curry・uncurry。考えは Schönfinkel（1924 年）、名は Curry から。
部分適用引数の一部だけを渡し、残りを待つ関数を得ること。add 3 :: Int -> Int。
関数合成(f . g) x = f (g x)。g の出力の型と f の入力の型が同じときだけつながる。
畳み込み（fold）リストの : を f に、[] を z に置き換えて 1 つの値にする高階関数。foldr (+) 0 [3,2,1] ＝ 6。
末尾呼び出し関数が最後にすることが、ほかの関数（自分も含む）を呼ぶことだけの呼び出し。枠を使い回せる。gcc 15.2 -O2 では 3 命令のループ。
累積引数途中の結果を運ぶ引数。go acc n の acc。第6章の sum が書き換えていた値を、引数で次の呼び出しへ渡す。
