1字句に切る — CssTokenizer

css/token.rs171 文字31 トークンmatch c

第33章の木では、style 要素の下に CSS の文字列が Text ノードとして入っている。saba はその文字列を取り出し、1 文字ずつ見て CssToken の列に切る。空白と改行はここで捨てる。

next() が 1 回に 1 トークンを返す Iterator の形は、第32章 場面1の HTML のトークナイザと同じ。違いは状態機械が無いこと。CSS の字句は先頭の数文字で種類が決まるため、match の腕と consume_* の小さな関数で足りる。

2規則の木 — CssParser と CSSOM

css/cssom.rsPeekable4 規則再帰下降

トークンの列を、規則 → セレクタと宣言 → プロパティと値、と降りながら構造体に組む。先読み（peek）で次のトークンを見てから消費を決める、再帰下降のパーサである。

saba の関数名は CSS Syntax 3 の構文解析の節の名前で、doc コメントに節の URL がある。現行の版（2026 年 10 月）は入れ子の規則のために書き直され、規則の列・宣言の列は stylesheet の中身・ブロックの中身に変わった。

3セレクタ — 3 種と is_node_selected

enum Selector#id .class 型layout_object.rs 307〜336

規則がどの要素に当たるかを決めるのがセレクタ。saba は型・クラス・ID の 3 種だけを持ち、要素の名前と class・id 属性の値を文字列として比べる。

Selectors 4 では、セレクタは単純セレクタ（型・クラス・ID・属性・擬似クラスなど）、それを並べた複合セレクタ、結合子でつないだ複雑セレクタ、コンマで並べたリストの 4 段。saba にあるのは単純セレクタ 3 種だけで、並べる・つなぐ・列挙するの 3 つは無い。

4当てはめる — 上書きのカスケード

create_layout_objectcascading_styleColor 18 色

DOM の各ノードに規則を当てはめて ComputedStyle を作る。saba のカスケードは、当たった規則を書かれた順に上書きするだけで、詳細度も出所も見ない。色は 18 色の表、display は 3 値。

CSS Cascade の勝ち負けは、出所と !important → 詳細度 → 書かれた順で決まる（第10章 場面3）。saba は同じ文書の style 要素 1 つしか読まないので出所は 1 つで、詳細度も見ないため、残るのは書かれた順だけになる。

5継承と初期値 — defaulting

ComputedStyleOptionCopy と Clone

規則が触らなかった欄は、親の値を写すか初期値で埋める。saba は「親の値が初期値と違えば写す」の 1 規則で継承を近似し、残りを要素の種類から決めた初期値で埋める。

CSS の継承はプロパティごとに決まる。color と font-size は継承し、background-color はしない。text-decoration は継承せず、装飾が箱の木を伝わる。saba はこの違いを「初期値と違えば写す」の 1 規則で近似する。

7まとめ — CSS とスタイル

  1. style の Text（171 文字）を 1 文字ずつ match で分け、12 種の CssToken にする。空白と改行は捨て、31 個になる。対応しない文字は unimplemented! で止まる（1）。
  2. CssParser は Peekable で次のトークンを先読みし、規則 → セレクタ → 宣言 → 値と降りる再帰下降。結果は StyleSheet { rules: Vec<QualifiedRule> }、test.html で 4 つ（2）。
  3. セレクタは TypeSelector・ClassSelector・IdSelector と Unknown。a:hover は a、@ 規則は読み飛ばし、並べたセレクタは最後の 1 つが残る。照合は名前と属性の文字列の一致（3）。
  4. 当たった規則を書かれた順に上書きする。background-color・color・display だけを見て、色は 18 色の表で Color { name, code } に、display は 3 値に。失敗は黒・白・none に落ちる（4）。
  5. defaulting は、親の値が初期値と違えば写し、残りを要素の種類から決めた初期値で埋める。h1 の Text は red と XXLarge、a の Text は Underline を受け取る（5）。
  6. この版はプロパティ 3 つ・色 18・セレクタ 3 種。CSSOM の木は Vec、カスケードは順序だけ、継承は近似。各ノードの ComputedStyle は LayoutObject の欄として次の章へ（6）。
CssTokenCSS の字句。saba は 12 種（HashToken・Delim・Number・Colon・SemiColon・括弧 4 種・Ident・StringToken・AtKeyword）。CSS Syntax 3 は 25 種。#title は HashToken("#title")。
StyleSheet・QualifiedRuleCSSOM の saba 版。StyleSheet は rules: Vec<QualifiedRule>、QualifiedRule は selector と declarations。test.html では規則 4 つ、宣言は各 1 つ。
Declaration・ComponentValueプロパティ名（String）と値。値の型 ComponentValue は type で CssToken の別名にしてあり、トークン 1 個だけ（仕様は入れ子を持てる）。
SelectorTypeSelector(String)・ClassSelector(String)・IdSelector(String)・UnknownSelector の enum。Selectors 4 の単純セレクタのうち 3 種。
Peekable反復子を包み、次の要素を消費せずに見る peek() を足す型（core::iter）。CssParser は t: Peekable<CssTokenizer> を持つ。
カスケード（saba）当たった規則の宣言を書かれた順に上書きすること。出所・詳細度・!important は見ない。実際の CSS は出所 → 詳細度 → 書かれた順。
ComputedStyleノードごとの計算済みの値。7 欄（background_color・color・display・font_size・text_decoration・height・width）がすべて Option で、埋めてから読む。
defaulting規則で決まらなかった欄を埋める手順。親の値が初期値と違えば写し（継承の近似）、残りを初期値（白・黒・要素の種類で決まる display・font_size・text_decoration、0.0）で埋める。
Colorname: Option<String> と code: String（#rrggbb）。from_name と from_code は 18 色だけを受け付け、外れると Err。code_u32 で 0x0000ff などの数に。
DisplayType・FontSizedisplay の値 Block・Inline・DisplayNone と、文字の大きさ Medium・XLarge（h2）・XXLarge（h1）。どちらも Copy の小さな enum。
